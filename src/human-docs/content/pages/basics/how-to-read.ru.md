Каждый раздел — Digest, Projects, Платформа — устроен одинаково. **Начало** даёт картину целиком за пять минут. **Руководство** объясняет, что ты видишь и что нажимать. **Как устроено** показывает механизм изнутри. **Почему так** собирает решения, которые определили устройство. **Справочник** держит точные таблицы, собранные прямо из кода. В шапке каждой страницы видно её слой и примерное время чтения.

## Обозначения на схемах

Все схемы нарисованы одним набором фигур, и у каждой фигуры одно значение.

```diagram
kind: graph
title: Легенда
desc: Процесс — прямоугольник, хранилище — цилиндр, внешний сервис — пунктирная рамка, ты — красная рамка. Состояния — овалы: успех зелёный с двойной рамкой, сбой красный, ожидание тебя — жёлтый пунктир. Проверка — шестиугольник, таблица базы — карточка с полями, пометка — рукописный текст.
node owner "Ты" "твоё действие" owner at 0,0
node process "Процесс" "часть Kurami" at 1,0
node store "Хранилище" "база или файлы" store at 2,0
node external "Внешний сервис" "GitHub, Discord" external at 0,1
node state "Состояние" at 1,1
node done "Успех" end at 2,1
node fail "Сбой" fail at 0,2
node wait "Ждёт тебя" wait at 1,2
node check "Проверка?" decision at 2,2
node table "таблица" "поле · поле · поле" entity at 0,3
node note "рукописная пометка — пояснение к соседнему узлу" note at 1,3
edge owner -> process "обычный шаг"
edge process -> store "асинхронно" dashed
edge state -> fail "путь сбоя" accent
```

Стрелки показывают направление действия: кто кому что передаёт. Сплошная стрелка — обычный шаг, пунктир — асинхронный или необязательный, красная — путь сбоя или внимания. Пунктирная рамка вокруг группы узлов — граница: сервер, продукт, процесс. Серые полосы во всю ширину — слои системы.

Кроме графов бывают ещё два вида схем. **Последовательность** — колонки участников и стрелки сообщений сверху вниз по времени. **Сутки** — полосы по часам, на которых видно, что и когда запускается.

## Договорённости о словах

- **Ты** — владелец системы. Всё, что названо «твоё решение», Kurami не делает сама.
- **Запуск** — одна попытка сделать одну задачу с доски. У задачи может быть несколько запусков.
- **Выпуск** — одна страница Daily за один день.
- **Точный коммит** — SHA последнего коммита PR. Проверки, ревью и превью относятся к нему, а не к PR вообще.
- Имена из кода — состояния, таблицы, файлы — даны `моноширинным шрифтом` и совпадают с кодом буква в букву.
- Время дано по местному времени, если не сказано «UTC».
- Прочерк «—» означает «неизвестно», а не ноль.

## Примеры и карты кода

Блок **Пример** проводит одну вымышленную задачу, выпуск или проверку через весь механизм страницы. Данные в нём придуманы, но имена веток, состояний и кнопок настоящие. Блок **Гарантии** перечисляет то, что система намеренно никогда не делает сама. **Где это в коде** в конце страницы ведёт к файлам, с которых стоит начать чтение исходников.
