Hub — это одна страница «как дела у всей системы». Она только читает: открывает базу Project Orchestrator и локальные репозитории на чтение, не ходит в GitHub и ничего не запускает. Сервис `kurami-hub` слушает только `127.0.0.1:8800`, а вход охраняет Cloudflare Access ([Внешний доступ](@access)). Страница установлена как приложение (PWA), но данные не кэширует: офлайн она показывает только заглушку «Нет связи».

## Что на странице

| Блок | Что показывает | Откуда |
|---|---|---|
| **В работе** | запуски в состояниях `starting`, `running`, `handoff_pending`, `remote_owned` | таблица `runs` |
| **Human Review** | карточки доски в колонке ревью | последний успешный опрос доски |
| **Нужен владелец** | запуски в состояниях `waiting_human` и `needs_attention` | таблица `runs` |
| **Коммиты · 30 дн.** | коммиты базовых веток всех репозиториев | локальный `git log` |
| **Codex** | токены за 7 и 30 дней, кэш, вывод, лимиты, пять самых частых моделей | локальные логи Codex |
| **Проекты** | по строке на проект: карточки «В работе» и Review, коммиты за 7 и 30 дней, свежесть опроса | база, Git |
| **Коммиты по неделям** | 12 недель по UTC, сумма по репозиториям | локальный `git log` |

Kurami в таблице проектов — не проект оркестратора, а четвёртый репозиторий: у него есть только коммиты. Колонка «В работе» в таблице считает карточки доски в колонке In progress, а плитка «В работе» сверху — запуски. Это два разных числа.

## Откуда берутся числа

Hub читает четыре источника, и все они локальные:

- `$KURAMI_HOME/config/projects.yaml` — список проектов и названия колонок;
- `$KURAMI_HOME/state/orchestrator.db` — открывается только на чтение, с таймаутом в секунду;
- `git log` в каждом каноническом репозитории на базовой ветке (Kurami — ветка `main`), за 91 день, с таймаутом в 4 секунды;
- `state_5.sqlite` Codex и файлы сессий, на которые он ссылается. Hub один раз читает их целиком и дальше дочитывает только новые байты.

Из логов Codex берётся накопленный счётчик токенов каждой сессии и разница между соседними событиями; если счётчика нет, используются записи по ответам. Кэш входит во входные токены, вывод включает токены рассуждений. Полоса лимита показывает последнее значение из локального журнала и исчезает после времени сброса. Точный текущий лимит — в панели использования Codex.

## Свежесть и пустые места

Числа по доске берутся из последнего успешного опроса. Hub помечает проект «Project · актуально», если попытка была успешной и снимок младше 15 минут, и «Project · устарело», если нет. Сервер кэширует снимок 45 секунд, а браузер каждую минуту запрашивает новый кусок страницы, пока вкладка открыта и фокус не внутри блока.

Если источника нет, Hub пишет «—», «Git · нет данных» или «Частичные логи» и не подставляет ноль: ноль означал бы, что работы нет, а «—» — что мы не знаем. Если обновление не удалось, браузер оставляет прежние значения и пишет «Нет связи · последние данные».

| Что видишь | Что значит |
|---|---|
| «Project · устарело» | последний опрос доски неудачен или старше 15 минут — смотри карточки в Discord |
| «Git · нет данных» | репозиторий не найден или команда не ответила за 4 секунды |
| «Частичные логи» | часть файлов сессий Codex недоступна, токенов может быть больше |
| «Нет связи · последние данные» | браузер не получил обновление, значения на странице старые |
| страница не открывается | сервис `kurami-hub` не запущен или Access не пускает |

## Чего Hub не делает

Hub не считает стоимость в деньгах и число закрытых PR. Он не отдаёт логи и промпты Codex и не показывает локальные пути: страница получает только числа и названия. Внутри у Hub нет входа: любой, кто дошёл до порта, видит всё, поэтому порт открыт только для `127.0.0.1`. Как ограничен сам сервис — в [Каталоги, процессы и выкладка](@runtime-layout).

:::code-map
- `src/hub/server.ts` — HTTP-сервер: маршруты, заголовки, кэш снимка на 45 секунд
- `src/hub/snapshot.ts` — сбор данных: база, Git, свежесть
- `src/hub/codex.ts` — чтение локальных логов Codex
- `src/hub/render.ts` — разметка страницы из библиотеки UI
- `deploy/systemd/kurami-hub.service` — сервис с доступом только на чтение
- `docs/hub.md` — как читать числа
:::
